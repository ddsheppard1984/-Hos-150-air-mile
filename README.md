# HOS 150 Air-Mile Assistant
Mobile-first helper for the FMCSA CDL property-carrier short-haul exception, 49 CFR 395.1(e)(1).

## Included
- 150 air-mile / 172.6 statute-mile geographic test
- Reporting-location save
- Destination and GPS checks
- Live GPS boundary monitoring
- 14-hour duty-window countdown
- 11-hour driving-time tracker
- Return-to-base/distance display
- Short-haul time-record entry and CSV export
- Manual RODS-required day tracker
- HOS rules/checklist
- Installable PWA shell

## Important
This app is a compliance aid, not a legal determination or a replacement for an ELD, carrier records, or safety department. If a driver fails a short-haul condition, standard RODS/HOS requirements may apply.

## Deploy on GitHub Pages
Upload all four files to a repository, then Settings → Pages → Deploy from branch → main/root. Open the Pages URL on the phone and use Add to Home Screen.
